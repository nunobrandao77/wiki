FOG Project: imagens de computadores

Uma ferramenta gratuita de código aberto para capturar imagens de discos e restaurá-las noutras máquinas, com arranque pela rede.

O que é o FOG Project?

O FOG Project é um sistema livre de gestão e clonagem de computadores, instalado num servidor Linux. Permite capturar uma imagem do disco de um computador e distribuí-la para outros, usando arranque pela rede (PXE/iPXE). Possui uma interface web para gerir computadores, imagens e tarefas.

Estado no Home Lab: o servidor iVentoy da VM 300 já está documentado, com a biblioteca de ISOs. O FOG ainda não está instalado. Esta página descreve funcionalidades documentadas oficialmente e uma possível utilização futura.

Uma ISO não é o mesmo que uma imagem de computador

ISO de instalação

Normalmente contém o instalador de um sistema operativo ou uma ferramenta. O iVentoy permite disponibilizar ISOs compatíveis no arranque pela rede.

Imagem de disco

É uma cópia do conteúdo de um disco/partições de uma máquina de referência; o FOG pode capturá-la e restaurá-la noutras máquinas compatíveis.

A vantagem da segunda abordagem é que a imagem pode incluir o sistema já preparado e aplicações instaladas, desde que respeitados os requisitos de preparação, licenciamento, identidade e compatibilidade dos computadores.

Onde é útil numa empresa?

Numa organização com muitos computadores semelhantes, em vez de repetir manualmente toda a preparação em cada máquina, a equipa técnica pode preparar um equipamento de referência, capturar a sua imagem no FOG e distribuí-la para os restantes computadores compatíveis.

Instalações uniformes

Uma base de software comum pode ser reaproveitada em computadores compatíveis.

Menos suportes físicos

O arranque e a distribuição podem ocorrer pela rede, evitando preparar pens USB e discos para cada máquina.

Unicast

Distribuição dirigida a um computador de cada vez, com uma transferência por destino.

Multicast

Distribuição de uma imagem a vários destinos através do mesmo fluxo, quando a rede e os clientes estão preparados para isso.

Não é um processo universal nem automático por magia: preparar imagens para Windows pode envolver Sysprep; podem existir diferenças de hardware, drivers, firmware UEFI/BIOS, Secure Boot, licenças e capacidade de disco. A implementação tem de ser validada antes de repor uma imagem porque o processo pode sobrescrever dados nos equipamentos de destino.

Como entra o PXE neste processo?

O arranque PXE permite ao computador iniciar um ambiente de rede antes do sistema instalado no disco. O FOG utiliza PXE/iPXE e um pequeno ambiente Linux para realizar operações como captura e distribuição da imagem.

Se já existir DHCP na rede, não é obrigatório criar outro servidor DHCP no FOG. É necessário configurar corretamente as opções de arranque ou outra abordagem compatível. No Home Lab, isto exige cuidado adicional porque já existe iVentoy: não se devem ativar dois serviços de arranque concorrentes na mesma rede sem uma estratégia definida.

Possível experiência futura no Proxmox

Uma opção para experimentar o FOG é criar uma VM Linux independente, com armazenamento suficiente para imagens e ligação inicial a uma rede de laboratório isolada, antes de a integrar com o DHCP principal. É uma proposta de teste, não uma configuração realizada.

O objetivo de uma experiência futura seria validar o registo de um computador de teste, a captura de uma imagem e a sua recuperação noutra máquina compatível, sem alterar os serviços de produção.
